Administración de Perfumes

¿Cómo funciona esto?
1. Agrega o elimina perfumes aquí abajo.
2. Cuando termines, haz clic en el botón verde "Descargar productos.json".
3. Reemplaza el archivo productos.json de tu carpeta con el nuevo archivo descargado.
4. Abre GitHub Desktop y sube los cambios para que se actualice la página pública.
